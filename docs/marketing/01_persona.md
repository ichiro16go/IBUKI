### 心理プロファイル

#### 感じている課題・ペイン

| カテゴリ | 詳細 |
|----------|------|
| **虚無感** | 毎日2-3時間SNSを見ているが、何も残らない。翌日覚えているコンテンツは1つもない |
| **疎外感** | ゼミの友人がキャンプや料理の話で盛り上がっている時、話に入れない。新たな趣味が欲しい |
| **焦り** | 就活も近いのに「趣味は？」と聞かれたら答えられない自分への焦り |
| **行動障壁** | 新しいことを始めたいが、何から手をつければいいかわからない。ハードルが高く感じる |

#### 内なる欲求

> 「誰かの"好き"に触れて、自分も何かに熱くなりたい」
>
> 「でも、自分から探すのは面倒だし、失敗したくない」
>
> 「偶然の出会いで、自然に始められたらいいのに」

#### 性格特性

- **受動的探索型**: 能動的に探すより、流れてくる情報を受け取りたい
- **社会的承認欲求**: 趣味を持つこと自体より、「趣味がある人」として見られたい面もある
- **完璧主義傾向**: 始めるなら「ちゃんと」やりたい。中途半端が嫌い
- **FOMO（見逃し恐怖）**: みんなが楽しんでいるものに乗り遅れたくない

### Ibuki利用シナリオ

#### 出会い（Day 1）

```
[通学中の電車内]
田中のスマホに通知:
「すれ違った人の"suki"を受け取りました: ミニチュアフード製作」

田中: 「ミニチュアフード？何それ」
→ suki_cardをタップ
→ 説明文とすでに熱狂している人の写真を見る
→ 「へぇ、こんな趣味あるんだ」
→ 図鑑に保存
```

#### 探索（Day 3）

```
[暇な空きコマ]
図鑑を眺める
「あのミニチュアフードってやつ、気になるな」
→ suki_cardの「始め方ガイド」を見る
→ 「100均で材料揃うんだ。1000円以下で始められるのか」
→ ステータスを「興味あり」に変更
```

#### 行動（Day 7）

```
[バイト終わりにダイソーに寄る]
粘土とヘラを購入（合計440円）
→ 家で見よう見まねで作ってみる
→ suki_actionに写真を投稿
→ ステータスが「好き」に成長
```

#### 熱狂（Day 30）

```
作品が10個溜まった
友人に見せたら「すごい！」と言われた
→ Instagramにも投稿するようになった
<!-- instagramとの連携で、instagramの投稿とsuki_actionの紐づけとかできると面白いかも -->
→ ゼミでも「趣味何？」と聞かれて答えられるようになった
→ ステータスが「熱狂」に
```
