# Ibuki ポジショニングマップ

## 競合サービス一覧

### 直接競合

| サービス | 概要 | ターゲット | 強み | 弱み |
|----------|------|-----------|------|------|
| **すれちがい通信（任天堂）** | ゲーム機同士でデータ交換 | ゲームユーザー | 実績あり、認知度高 | ゲーム内限定、目的が異なる |
| **Tinder / Bumble** | 人とのマッチング | 恋愛・友人探し | 巨大ユーザーベース | 人が主役、趣味は副次的 |
| **Pinterest** | 画像ベースの発見 | クリエイター・主婦層 | ビジュアル訴求力 | アルゴリズム依存、偶然性なし |

### 間接競合

| サービス | 概要 | Ibukiとの違い |
|----------|------|----------------------|
| **TikTok** | ショート動画プラットフォーム | アルゴリズム推薦 vs 物理的偶然 |
| **趣味コミュニティアプリ（ミクシィ等）** | 既存趣味の深掘り | 既存趣味 vs 未知の趣味発見 |
| **Meetup** | イベント参加型の趣味発見 | 能動的参加 vs 受動的出会い |
| **note / Zenn** | 趣味・知識の発信 | 検索型 vs 偶然型 |

## ポジショニングマップ

### マップ1: 出会いの対象 × 出会いの方法

```
                    アルゴリズム推薦
                         |
                         |
         Pinterest  ●    |    ● TikTok
                         |
                         |
    Instagram ●          |          ● YouTube
                         |
  人との出会い ──────────┼────────── 趣味との出会い
                         |
                         |
      Tinder ●           |           ● Meetup
                         |
                         |
      Bumble ●           |    ★ Ibuki
                         |
                         |
                    物理的偶然
```

#### 解説

- **横軸**: 出会いの対象が「人」か「趣味・コンテンツ」か
- **縦軸**: 出会いの方法が「アルゴリズム」か「物理的偶然」か
- **Ibukiの位置**: 「趣味との出会い × 物理的偶然」という**ブルーオーシャン**

---

### マップ2: 匿名性 × 体験の深さ

```
                      匿名性 高
                         |
                         |
       5ch/匿名掲示板 ●  |    ★ Ibuki
                         |
                         |
    匿名SNS（Yay!） ●    |
                         |
  浅い体験 ─────────────┼───────────── 深い体験
  （発見のみ）           |              （行動変容）
                         |
                         |
       TikTok ●          |          ● Meetup
                         |
         Instagram ●     |     ● 趣味コミュニティ
                         |
                      匿名性 低
```

#### 解説

- **横軸**: 体験の深さ（発見だけで終わるか、行動変容まで導くか）
- **縦軸**: 匿名性のレベル
- **Ibukiの位置**: 「高い匿名性」を保ちながら「行動変容」まで導く

---

### マップ3: 継続動機のタイプ × コンテンツの新規性

```
                   既知のコンテンツ
                   （好きの深掘り）
                         |
                         |
   ファンクラブアプリ ●  |    ● Spotify
                         |
                         |
       note ●            |          ● YouTube
                         |
  外発的動機 ────────────┼──────────── 内発的動機
  （報酬・ランキング）   |             （収集・成長）
                         |
                         |
    ポイ活アプリ ●       |       ★ Ibuki
                         |
                         |
            　　          |   
                         |
                   未知のコンテンツ
                   （新発見）
```

#### 解説

- **横軸**: 継続動機のタイプ（外発的 vs 内発的）
- **縦軸**: コンテンツの新規性（既知の深掘り vs 未知の発見）
- **Ibukiの位置**: 「未知の発見 × 内発的動機（図鑑収集）」

## 競合との詳細比較

### vs すれちがい通信（任天堂）

| 比較軸 | すれちがい通信 | Ibuki |
|--------|---------------|---------------|
| 目的 | ゲーム内アイテム交換 | 趣味発見・行動変容 |
| デバイス | ゲーム機限定 | スマートフォン |
| コンテンツ | ゲームデータ | 趣味カード |
| 継続動機 | ゲームクリア | 図鑑コンプリート |

**差別化ポイント**: 「ゲームの一機能」ではなく「ライフスタイル変革」が目的

---

### vs Tinder / Bumble

| 比較軸 | Tinder / Bumble | Ibuki |
|--------|-----------------|---------------|
| 流れるもの | 人のプロフィール | 趣味カード |
| 匿名性 | 低（顔写真必須） | 高（完全匿名） |
| 目的 | 人との繋がり | 趣味との出会い |
| 心理的負担 | 高（ジャッジされる） | 低（趣味だけ） |

**差別化ポイント**: 「人ではなく趣味だけが流れる」安心感と気軽さ

---

### vs Pinterest

| 比較軸 | Pinterest | Ibuki |
|--------|-----------|---------------|
| 発見方法 | アルゴリズム推薦 | 物理的すれ違い |
| フィルターバブル | あり（興味ベースで最適化） | なし（完全ランダム） |
| 出会いのストーリー | なし | あり（「あの場所で出会った」） |
| 継続動機 | ピン保存 | 図鑑収集・ステータス成長 |

**差別化ポイント**: アルゴリズムではなく「リアルな偶然」による脱フィルターバブル

---

### vs TikTok

| 比較軸 | TikTok | Ibuki |
|--------|--------|---------------|
| コンテンツ供給 | 無限スクロール | すれ違いによる有限 |
| 偶然性 | 擬似的（アルゴリズム） | 本物（物理的） |
| 行動変容 | 弱い（視聴で終わり） | 強い（始め方ガイド） |
| 時間の使い方 | 消費 | 蓄積（図鑑） |

**差別化ポイント**: 「消費」から「蓄積」へ。図鑑が自分だけの資産になる

## ポジショニング・ステートメント

### 競合と比較した独自ポジション

> **Ibukiは、**
>
> TikTokやPinterestのような「アルゴリズムが選んだコンテンツ」ではなく、
>
> Tinderのような「人とのマッチング」でもなく、
>
> **「物理的なすれ違い」を通じて「趣味だけ」が偶然流れてくる**
>
> 唯一無二のサービスです。
>
> **完全匿名**で心理的ハードルが低く、
>
> **図鑑収集**という内発的動機で継続し、
>
> **始め方ガイド**で実際の行動変容まで導きます。

## 大手がやれない構造的理由

### Instagram / TikTok がやれない理由

| 観点 | 理由 |
|------|------|
| **広告モデルとの衝突** | 匿名で趣味だけが流れると、ユーザーの個人情報が取れず広告ターゲティングができない |
| **エンゲージメント設計** | 「すれ違い」は1日に数回。無限スクロールで滞在時間最大化を狙うモデルと相反 |
| **既存UXとの矛盾** | 既存ユーザーはプロフィール・フォロー関係を構築済み。匿名化は既存価値の毀損 |

### LINE がやれない理由

| 観点 | 理由 |
|------|------|
| **関係性ベースのUX** | LINEは「知っている人との連絡」が核。匿名の偶然出会いは世界観と矛盾 |
| **位置情報への敏感さ** | LINEは日本最大のメッセンジャー。位置情報活用は世論リスクが高い |

### 任天堂がやれない理由

| 観点 | 理由 |
|------|------|
| **ゲーム機限定** | スマートフォンでの常時接続型サービスは主力事業ではない |
| **ハードウェア依存** | すれ違い通信はゲーム機販促の一機能。独立サービス化の動機が薄い |

### 守るべきポジション

1. **「趣味だけが流れる」匿名性** → 人との繋がり機能を安易に追加しない
2. **「物理的偶然」の純粋性** → アルゴリズム推薦を入れすぎない
3. **「図鑑収集」の内発的動機** → ランキングやポイントなど外発的動機に頼りすぎない
