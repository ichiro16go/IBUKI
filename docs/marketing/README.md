## 活用方法

### プレゼンテーション準備

1. **ペルソナ**を読んで、田中翔太のストーリーを頭に入れる
2. **ポジショニングマップ**で競合との違いを説明できるようにする
3. **収益モデル**の数字を把握し、質問に答えられるようにする
4. **プレゼンストーリー**に沿って練習する

### 開発優先度の判断

- **ペルソナの課題**から、最優先で解決すべき機能を判断
- **フライホイール**から、成長のボトルネックを特定

### 審査員への対応

- **想定Q&A**（プレゼンストーリー内）を確認
- **収益モデルの整合性**を説明できるようにする
