## 収益モデル概要

```

│        │  基本機能                    │  プレミアム機能    │
│        │  ・すれ違い検知              │  ・範囲拡大        │
│        │  ・図鑑収集                  │  ・履歴閲覧        │

│        └──────────┬─────────────────┬┘                    │
│                   │                 │                      │
│                   ▼                 ▼                      │
│         [趣味関連サービスへの送客]                         │
```

### 1. サブスクリプション収益

#### プラン設計

| プラン | 月額 | 年額 | 提供機能 |
|--------|------|------|----------|
| **Free** | ¥0 | - | 基本機能すべて |
| **Premium** | ¥500 | ¥4,800 | 下記参照 |

#### Premium機能一覧（¥500/月）

| 機能 | 説明 | ユーザー価値 |
|------|------|-------------|
| **すれ違い範囲拡大** | 10m → 50m | より多くのsukiと出会える（物理的閾値の拡大） |

| **趣味ログ無制限** | 月10件 → 無制限 | シングルプレイヤー価値の強化 |

※ 「レア出現率UP」等のアルゴリズム介入はコンセプト（偶然性）に反するため採用しない

#### Premium+機能一覧（¥980/月）

| 機能 | 説明 | ユーザー価値 |
|------|------|-------------|
| **Premium全機能** | - | - |

### 2. 手数料収益（アフィリエイト）

#### モデル概要

```
[ユーザー] ──→ [sukiカードを見る]
                    │
                    ▼
            「始めてみたい！」
                    │
                    ▼
            [始め方ガイド]
                    │
                    ├── 近くの体験スポット
                    ├── おすすめ入門道具
                    └── オンライン講座
                    │
                    ▼
            [提携サービスへ送客]
                    │
                    ▼
            [成約時に手数料 10%]
```

#### 提携先カテゴリ

| カテゴリ | 提携先例 | 想定単価 | 手数料率 |
|----------|----------|----------|----------|
| **体験予約** | asoview!, じゃらん体験 | ¥5,000 | 10% = ¥500 |
| **ECサイト** | Amazon, 楽天, 専門EC | ¥3,000 | 3-8% = ¥150 |
| **オンライン講座** | Udemy, ストアカ | ¥10,000 | 10% = ¥1,000 |
| **サブスク** | Spotify, Kindle Unlimited | ¥980/月 | 初月100% = ¥980 |

#### 手数料収益のフロー

1. ユーザーがsukiカードから「始め方」をタップ
2. 提携サービスの商品・体験がレコメンド表示
3. ユーザーが購入・予約
4. 提携先から手数料を受領

---

### 3. データ活用収益（限定的）

#### 匿名性との両立

| データ | 収集 | 活用可否 | 理由 |
|--------|------|----------|------|
| 個人位置情報 | 判定後破棄 | ✕ | プライバシー最優先 |
| 趣味トレンド（匿名集計） | ○ | ○ | 匿名化されたトレンドデータ |
| エリア別趣味分布（匿名集計） | ○ | ○ | 地域マーケティング活用 |

#### 活用例

- 「渋谷エリアで今月急上昇中の趣味トップ10」をメディアに提供
- 趣味関連企業へのマーケティングインサイト提供
- ※ 個人は特定されない、集計データのみ

## 単位経済性（Unit Economics）

### LTV（顧客生涯価値）

| 要素 | 数値 | 計算根拠 |
|------|------|----------|
| 平均利用期間 | 18ヶ月 | 趣味アプリの平均 |
| 月間ARPU（無料込み） | ¥100 | 課金率3% × ¥500 + 手数料 |
| **LTV** | **¥1,800** | ¥100 × 18 |

### CAC（顧客獲得コスト）

| チャネル | CPI | コンバージョン | CAC |
|----------|-----|----------------|-----|
| 口コミ・オーガニック | ¥0 | - | ¥0 |
| インフルエンサー | ¥100,000 | 1,000人 | ¥100 |
| 趣味イベント連携 | ¥200,000/イベント | 1,000人 | ¥200 |
| SNS広告 | ¥300/クリック | 10% | ¥3,000 |

#### 加重平均CAC（想定チャネルミックス）

| チャネル | 構成比 | CAC | 加重CAC |
|----------|--------|-----|---------|
| オーガニック | 40% | ¥0 | ¥0 |
| インフルエンサー | 30% | ¥100 | ¥30 |
| イベント連携 | 15% | ¥200 | ¥30 |
| SNS広告 | 15% | ¥3,000 | ¥450 |
| **合計** | 100% | - | **¥510** |

### LTV/CAC比率

```
LTV ÷ CAC = ¥1,800 ÷ ¥510 = 3.5x

→ 健全水準（3x以上が理想）を達成
```

## 収益モデルの整合性チェック

### 世界観との整合

| 収益源 | 匿名性 | 偶然性 | 判定 |
|--------|--------|--------|------|
| サブスクリプション | ○ 影響なし | ○ 影響なし | ✓ 採用 |
| 手数料（送客） | ○ 匿名で利用可 | ○ 偶然の出会いが起点 | ✓ 採用 |
| ターゲティング広告 | ✕ 個人情報必要 | ✕ アルゴリズム介入 | ✗ 非採用 |
| データ販売（個人） | ✕ プライバシー侵害 | - | ✗ 非採用 |
