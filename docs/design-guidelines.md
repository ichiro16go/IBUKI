# Ibuki デザインガイドライン v1

## 1. デザインコンセプト

Ibukiは「効率化」ではなく、無作為な出会いから生まれる「好き」を育てる体験を重視する。  
UIは速さや情報密度よりも、余白・あたたかさ・愛着を優先する。

キーワード:

- あたたかい
- ゆるい
- 育てる
- 余白のある

## 2. カラールール

参照パレット: https://colorhunt.co/palette/b17f59a5b68dc1cfa1ede8dc

| 用途 | 色 | 使い方 |
|---|---|---|
| ベース背景 | `#EDE8DC` | 画面背景の基本色 |
| サブ背景 | `#C1CFA1` | カード下地、セクション背景 |
| 成長/成功 | `#A5B68D` | 状態の前進、ポジティブ表示 |
| アクセント | `#B17F59` | CTA、選択中、重要要素 |
| シグナル | `#B45E57` | すれ違い、ハート、進行中の通知 |

運用ルール:

- 1画面でアクセント色の面積を増やしすぎない（主役はコンテンツ）
- CTA とシグナルは同じ色にしない
- コントラスト不足が出る箇所は文字色で調整し、背景色は極力固定

## 3. タイポグラフィ

| 種別 | 採用フォント | 用途 |
|---|---|---|
| 和文 | Zen Maru Gothic | 見出し・本文 |
| 欧文 | M PLUS | 英数字、ラベル、補助テキスト |

運用ルール:

- 本文はRegular中心（読みやすさ優先）
- 見出しのみMedium/SemiBoldを使用
- 強調を太字に頼りすぎず、余白とサイズ差で階層を作る

## 4. ステータス表現（趣味の成熟度）

文言は以下を維持する:

- 興味あり
- 好き
- 大好き
- 熱狂

ただし表現は植物メタファーを使う（色・アイコン）:

- 興味あり: 種
- 好き: 芽
- 大好き: 葉
- 熱狂: 花

## 5. UIスタイル指針

- 角はやや丸め（やさしさを優先）
- 余白を広めに取り、詰め込みすぎない
- 1画面1主目的（迷いにくさ）
- 効率化アプリ的な無機質UI（直線・高密度・寒色過多）を避ける
